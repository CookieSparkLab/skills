# 暖纸野兽派 Deck · 设计规范

> **这是唯一权威版本。** 改规范只改这一份，别在别处再抄一份。

核心心法：**暖纸底 + 硬边 + 实心阴影 + 直角**。

---

## 1 · 配色

| token | 值 | 用在哪 |
|-------|-----|------|
| `--paper` | `#f5f1e8` | 整页背景。**别用纯白** |
| `--paper-2` | `#ffffff` | 卡面 |
| `--ink` | `#0e0e0e` | 文字 + **所有边框 + 所有阴影** |
| `--muted` | `#5a5a55` | 次要灰字 |
| `--coral` | `#DC5C5D` | 主强调色，克制用 |
| `--blue` | `#B6CEED` | 雾蓝 |
| `--sage` | `#d7e7d4` | 灰绿 |
| `--mint` | `#cde2da` | 薄荷 |
| `--pink` | `#ffe9f8` | 浅粉，标签底 |

- 大面积留给纸底和白卡，六个彩色只用在卡片底、标签、强调块。
- 背景叠一层 32px 橄榄绿网格 `rgba(144,153,26,.22)`。

## 2 · 字体

- 正文和标题统一 **HarmonyOS Sans SC**（中英兼优，中西文同一家族才协调）
- 等宽、角标、编号用 **IBM Plex Mono**
- 字重只用 **500 / 700 / 900**，没有第四种

## 3 · 字号：9 个角色，绝不新增

| 类名 | 尺寸 / 字重 | 用途 |
|------|-----------|------|
| `.t-display` | 212 / 900 | 封面大标题 |
| `.t-title` | 168 / 900 | 过场页、大字页 |
| `.t-section` | 96 / 900 | 每页大标题 |
| `.t-cardtitle` | 72 / 900 | 卡片大标题、编号 |
| `.t-subhead-lg` | 56 / 500 灰 | 大副标题 |
| `.t-subhead-md` | 44 / 900 | 卡片标题 |
| `.t-kicker` | 44 / 500 灰 | 标签说明 |
| `.t-body` | 32 / 500 | 正文 |
| `.t-body-sm` | 28 / 500 | 次级正文 |

**想做层级？用颜色（muted）和字重，不要造新字号。**
封面标题嫌大可以在 `.t-display` 上覆盖成 176px，这是唯一允许的例外。

## 4 · 阴影 / 形状 / 间距

- 阴影三档，纯黑、往右下偏移、**无 blur**：`sm 2px 2px` · `base 4px 4px` · `lg 6px 6px`
- **一律直角** `border-radius: 0`。卡片、标签、数字块、图片框全部直角
- 卡片 = `3px solid ink` + lg 阴影 + 直角 + `48px 52px` 内边距
- 间距走 8px 刻度：8 / 16 / 24 / 32 / 48 / 64
- **演示 deck 里卡片不做 hover 动效**，静止

---

## 5 · 排版法则（踩过的坑，逐条守）

1. **coral 上文字一律白色。** coral 卡片、coral 标签里的字白色；如果在 coral 上再放一个浅底标签，那个标签的文字要显式设回黑（`.card.coral .pill:not(.coral)` 已内建）。

2. **主描述 + 说明分两层。** 有「主 + 次」时，主描述用 `.t-body`（黑、正常字重），次要说明用 `.note`（灰 + 左竖线 + 缩进）。**不要让两行长得一样。**

3. **标签和说明之间留 8 到 10px。** 标题 / 标签与它下面的说明贴在一起，就分不出主次了。

4. **中文换行行高 1.3 到 1.35。** 会换行的中文标题和正文加 `.wrap-cn`。1.05 到 1.2 只留给单行大标题，多行中文顶格会挤成一坨。

5. **编号和标题要成一组。** 编号可以单独一行，但必须小间距（8 到 12px）+ 比例协调（编号约为标题的 1.2 到 1.3 倍）+ 整组垂直居中。**别搞「大数字 + 一大片留白 + 小字」。**

6. **内容默认顶部对齐。** 内容页正文从标题下面自然往下排。垂直居中只留给封面、过场、Q&A 这类单块居中的页。

7. **底部必须留白。** 画布定死 1920×1080，内容一定要放得下，底部留 60 到 80px，**绝不贴边、绝不裁切**。密了就收紧间距或者删内容，不要牺牲留白。

8. **中英文同一个字体家族。** 别中文一套、拉丁一套。

9. **卡片不做 hover。** 这是放映用的，不是网页。

10. **多卡片逐个出现，收尾句最后出。** 一页里有 2 / 3 / 6 张卡片，默认每张包一个 `step` 按 → 逐个淡入，全部出完才翻页。**页面底部的总结句、结论行也要作为最后一个 `step`**，排在所有卡片之后。顶部大标题、kicker、导语用 `reveal` 随页进入即可。

11. **一律直角，绝不圆角。** 图片也不例外 —— 要边框就用 3px 黑边 + 硬阴影，不要圆角配白色描边光晕那种做法。

---

## Do / Don't

- ✅ 直角、3px 黑边、实心无模糊阴影、暖米底、coral 白字、说明用左竖线、内容顶对齐、中西文同一字体
- ❌ 圆角、带 blur 的阴影、纯白背景、编号与标题脱节、中文多行顶格、内容贴底边、为了塞下而缩字号
- ❌ **卡片、标签、按钮上不要渐变**，元素一律实心

> 关于渐变：姊妹 skill `vibe-coding-saturday-style` 的页面底纹里有一道左绿右粉的横向 wash，那是允许的。
> **deck 不用那层 wash** —— 投影环境下它会让画面显脏，所以 deck 的底纹只有纸底 + 网格。
> 两边的共同规则是一样的：**渐变只可能出现在页面底纹，绝不出现在元素上。**
